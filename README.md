# Temu Dash 💸

Juego de plataformas rítmico original para navegador, pensado para Chromebook.

## Jugar localmente
Abre `index.html` en Chrome. No necesita instalación ni dependencias.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html` y `README.md` a la raíz.
3. En Settings → Pages, selecciona Deploy from a branch, `main`, `/ (root)`.
4. Espera a que GitHub Pages publique el sitio.

## Funciones de la primera versión
- Juego de saltos con obstáculos, progreso, monedas, intentos y récord de la sesión.
- Tres niveles de ejemplo.
- Editor básico de niveles y guardado local.
- Importar/exportar niveles como JSON.

## Limitación online
Esta versión no se conecta a los servidores oficiales de Geometry Dash. No hay una API web pública y documentada que garantice acceso desde un clon. Los niveles comunitarios son locales/importables; para niveles online reales se necesita un backend y almacenamiento propios o una integración compatible y autorizada.

## Controles
Espacio, flecha arriba, W, clic o toque para saltar.
