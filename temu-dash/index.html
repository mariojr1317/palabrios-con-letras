🌐 Buscar niveles de Geometry Dash

La búsqueda usa la API de GDBrowser; ya no necesitas una clave de corsproxy.dev. La disponibilidad depende de que la API permita solicitudes desde GitHub Pages.

Busca un nivel por nombre o pega su ID. También puedes cargar los JSON de niveles que descargaste anteriormente.

📂 Cargar datos guardados

Admite JSON que exportó Temu Dash anteriormente (con el campo encodedLevel), JSON de GDBrowser o una cadena de nivel en texto. Se descomprime y se convierten los objetos reconocidos al motor 2D.
